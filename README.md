# Vue Board

Vue 3와 TypeScript로 만든 현대적인 게시판 웹사이트입니다.

## ✨ 무엇을 할 수 있나요?

- **📝 게시글 작성 및 관리**: 글쓰기, 수정, 삭제가 쉽고 빠릅니다
- **🔍 강력한 검색**: 제목, 내용, 작성자별로 원하는 글을 찾을 수 있습니다  
- **📱 모바일 친화적**: 스마트폰에서도 편안하게 사용할 수 있습니다
- **🔐 안전한 로그인**: 개인정보를 안전하게 보호합니다
- **🌙 테마 선택**: 라이트/다크 테마를 자유롭게 전환할 수 있습니다
- **⚡ 빠른 반응**: 클릭하면 바로바로 반응하는 부드러운 사용자 경험

## 🛠 기술적 특징

이 프로젝트는 다음과 같은 최신 웹 기술로 만들어졌습니다:

- **Vue 3**: 사용자 인터페이스를 위한 최신 JavaScript 프레임워크
- **TypeScript**: 더 안전하고 예측 가능한 코드 작성
- **Vite**: 번개처럼 빠른 개발 서버와 빌드 도구
  - ⚡ **초고속 개발 서버**: 코드 변경 후 0.1초 만에 브라우저에서 확인 가능
  - 🔥 **핫 리로드**: 페이지 새로고침 없이 실시간 변경사항 반영
  - 📦 **최적화된 빌드**: 실제 서비스에서 사용할 파일들을 최소 크기로 압축
- **Pinia**: Vue 3에 최적화된 현대적 상태 관리 도구
- **반응형 디자인**: 데스크톱, 태블릿, 모바일 모든 화면에 최적화
- **컴포넌트 기반**: 재사용 가능한 UI 요소들로 일관된 디자인 유지

### 🚀 Vite의 장점

- **개발 속도**: 기존 도구보다 10-100배 빠른 개발 서버 시작
- **즉시 반영**: 코드 수정하면 바로 화면에서 확인 가능
- **미래 지향적**: 최신 ES 모듈 방식을 사용해 더 안정적

개발자를 위한 상세한 기술 문서는 [CLAUDE.md](./CLAUDE.md)를 참조하세요.

## 🚀 시작하기

프로젝트를 로컬에서 실행하려면 다음 단계를 따라하세요:

### 1. 프로젝트 설치
```bash
# 필요한 패키지를 설치합니다
npm install
```

### 2. 개발 서버 실행
```bash
# Vite 개발 서버를 시작합니다 (보통 http://localhost:5173에서 실행됩니다)
npm run dev
```
> 💡 **Vite의 마법**: 서버가 1-2초 안에 시작되고, 코드를 수정하면 즉시 브라우저에 반영됩니다!

### 3. 프로덕션 빌드 (선택사항)
```bash
# Vite로 배포용 파일을 생성합니다 (TypeScript 검사 + 최적화된 빌드)
npm run build

# Vite로 빌드 결과를 미리 확인합니다
npm run preview
```
> 🏗 **효율적인 빌드**: TypeScript 검사를 먼저 하고, 통과하면 Vite가 최적화된 파일들을 생성합니다
